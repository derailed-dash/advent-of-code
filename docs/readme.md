- If you're here looking for the source code for my Advent of Code solutions, you're in the wrong folder.  Navigate to the `/src` folder.
- If you're here looking for the walkthroughs, then [aoc.just2good.co.uk](https://aoc.just2good.co.uk/) is probably what you're after.
- Run `docker compose up` from the `docs` folder (or `make docs` from the repository root) for local Jekyll development; run `make docs-build` after changing `docs/Dockerfile` or `docs/Gemfile`.
- Ensure `docs/.env` exists (via `git-crypt-helper.sh sync-from-enc` or copied from [`docs/.env.template`](.env.template)) if you need to specify `JEKYLL_GITHUB_TOKEN`.
